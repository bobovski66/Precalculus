Row operations preserve the solution set

Goal: Practice Gaussian elimination as controlled transformations of an augmented matrix, while keeping track of the system’s solution type.

Choose a preset, then perform row operations. You can swap rows, multiply a row by a nonzero number, or add a multiple of one row to another.

1. Manipulate

Use row swaps, scaling, and row replacement on preset augmented matrices.

2. Observe

The visible matrix changes, but every legal row operation preserves the same solution set.

3. Interpret

Read pivot structure and contradiction rows to classify the system before finishing all arithmetic.

Meaning check: Before leaving the activity, be able to say what the changing graph or calculation tells you in the context of this week’s mathematics.
