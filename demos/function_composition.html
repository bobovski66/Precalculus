Which inputs are allowed?

Green means the calculation works; red means it stops at one of the functions. This strip covers inputs from −5 to 5. The domain written above it may extend further.

Questions to explore

  1. In “Order matters,” set x = 2. Compare “add three, then square” with “square, then add three.” What are the two answers?
  2. In “Logarithm domain,” test x = −2, 0, and 2. Which input makes the logarithm receive zero? Which one makes it receive a positive number?
  3. In “Square root of a logarithm,” try x = 0.5 and x = 1. The logarithm exists at both inputs. Why can you take the square root in only one case?
  4. In “Exponential peak,” compare x = −1, 0, and 1. Where is the highest point? Why do −1 and 1 give the same result?
