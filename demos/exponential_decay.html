Decay Lab — exponential functions

Start with a sample of radioactive atoms. Each tick, every surviving atom has the same fixed chance of decaying — so the more you have, the more you lose, and the count falls off exponentially: N = N₀·e^(−λt). Because decay is random, the real counts scatter around the smooth model. The half-life — the time to lose half the sample — stays the same no matter where you start.
