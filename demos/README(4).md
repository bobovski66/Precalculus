# Precalculus Interactive Demos

This repository contains browser-based interactive demos for Precalculus topics.  
Each demo is a standalone HTML file and can be opened directly through GitHub Pages.

## Live demos

- [Function Fit Lab](https://bobovski66.github.io/Precalculus/demos/function_fit.html)  
  Match a transformed parent function to a point cloud using parameters of the form  
  `A f(b(x-h)) + k`.

- [Polynomial Roots and Multiplicity Lab](https://bobovski66.github.io/Precalculus/demos/polynomial_roots.html)  
  Explore how roots and multiplicities determine the graph of a polynomial.

- [Rational Functions Lab](https://bobovski66.github.io/Precalculus/demos/rational_functions.html)  
  Identify zeros, vertical asymptotes, multiplicities, and end behavior of rational functions.

- [Transformations Lab](https://bobovski66.github.io/Precalculus/demos/transformations.html)  
  Practice graph transformations using shifts, stretches, compressions, and reflections.

## Topics covered

These demos are designed for a two-term community-college Precalculus sequence and emphasize:

- parent functions
- transformations
- polynomial roots
- root multiplicity
- rational function zeros
- vertical asymptotes
- end behavior
- factored and expanded forms
- visual fitting and model selection

## Using the demos

Students can use the links above directly in a browser.  
No installation is required.

The demos are meant to support classroom discussion, group work, and exploratory practice. They are especially useful when students are learning to connect algebraic structure with graphical behavior.

## Notes

These are instructional tools, not formal assessment software.  
The point is to help students build intuition by experimenting with functions and seeing immediate graphical feedback.
