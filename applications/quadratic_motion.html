Quadratic Motion — Vertical Toss

An object thrown straight upward has constant downward acceleration, so height is a quadratic function of time.

← Course LMS

Application: a parabola in motion

Goal: Connect the vertex and concavity of a height-versus-time quadratic with the peak of a vertical toss.
1. Manipulate

Change release height, initial upward speed, and observation time.

2. Observe

Watch the object move only up and down while its height-versus-time graph remains a downward-opening parabola.

3. Interpret

Use the vertex to interpret maximum height and the leading coefficient to interpret downward acceleration.

Meaning check: Before leaving the activity, explain what the graph or calculation tells you about the situation—not only which number you obtained.
