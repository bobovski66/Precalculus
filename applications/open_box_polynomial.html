Open-Box Polynomial Model — geometry becomes a cubic

Length24.0 cm
Width14.0 cm
Height3.0 cm
Volume1008 cm³
V(x) = x(30 − 2x)(20 − 2x)
= 4x³ − 100x² + 600x
Physical domain: 0 < x < 10. At x = 10 the 20 cm side collapses, so the box disappears.
Algebraic zeros: x = 0, 10, 15. Only the interval 0 < x < 10 describes an actual open box.
Largest physical volume: about 1056.3 cm³ at x ≈ 3.92 cm.
Class prompts: Why does each linear factor have a geometric meaning? Why is x = 15 a real zero of the polynomial but not a possible box? What does the turning point mean physically?
