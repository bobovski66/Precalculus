Absolute Value — Distance Sensor

A sensor reports distance, not signed position, so left and right positions fold onto the same V-shaped graph.

← Course LMS

Application: position becomes distance

Goal: Understand absolute value as a physical loss of direction information: distance remembers how far but not which side.
1. Manipulate

Move the sensor and the object independently.

2. Observe

Watch the vertex follow the sensor and compare symmetric positions on either side.

3. Interpret

Explain why an absolute-value output cannot, by itself, tell you which side of the sensor the object occupies.

Meaning check: Before leaving the activity, explain what the graph or calculation tells you about the situation—not only which number you obtained.
