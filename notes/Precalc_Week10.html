Matrices and Gaussian Elimination

Last week you simplified systems of equations by eliminating variables. This week we will learn a way to organize those same calculations, recognize what the resulting rows tell us, and use the method to solve problems in several different settings.

1. Keeping the numbers organized

Consider the system \(x+y=5\) and \(2x-y=1\). You probably remember how to solve it: adding the equations removes \(y\), leaving \(3x=6\). Then \(x=2\) and \(y=3\).

Look more closely at the addition. We combined the coefficients of \(x\), the coefficients of \(y\), and the numbers on the right of the equals signs. The letters themselves did not change.

We can arrange those numbers in a small table, with one row for each equation:

\[ \begin{aligned} x+y&=5\\ 2x-y&=1 \end{aligned} \qquad\longleftrightarrow\qquad \left[\begin{array}{cc|c}1&1&5\\2&-1&1\end{array}\right]. \]

This table of numbers is called an augmented matrix. The first column holds the coefficients of \(x\), the second holds the coefficients of \(y\), and the column after the bar holds the numbers on the right. The bar is there to help us keep the two sides of each equation straight.

Let's take the second row and subtract twice the first:

\[ [\,2\quad -1\mid1\,]-2[\,1\quad1\mid5\,] =[\,0\quad-3\mid-9\,]. \]

In equation form, that new row says \(-3y=-9\), so \(y=3\). We performed exactly the kind of elimination we already know, but without repeatedly writing the variables.

A matrix with three variables

The system

\[\begin{aligned}2x+y-z&=1,\\x-y+2z&=3,\\3x+2y+z&=10\end{aligned}\]

is written as

\[ \left[\begin{array}{ccc|c} 2&1&-1&1\\ 1&-1&2&3\\ 3&2&1&10 \end{array}\right]. \]

Each row still represents an equation. In the second row, \(1,-1,2\) belong to \(x,y,z\), respectively, and the \(3\) after the bar is the constant.

If an equation is missing a variable, that variable has coefficient zero. For example, \(x+3z=7\) would be written as \([\,1\quad0\quad3\mid7\,]\). The zero keeps the columns lined up.

Try it. Write the augmented matrix of \(3x-y=7\) and \(2y=4\), keeping the variable columns in the order \(x,y\).
Check the matrix

\(\left[\begin{array}{cc|c}3&-1&7\\0&2&4\end{array}\right]\). The second equation has no \(x\) term, so its first entry is zero.

2. What can we do to a row?

We are going to replace the original matrix with matrices that are easier to solve. But we cannot just change its entries however we like. A row represents an equation, so each change must preserve the solutions of the system.

There are three moves we are allowed to make:

  1. Swap two rows. This only changes the order in which the equations are written.
  2. Multiply a row by a nonzero number. This is the same as multiplying both sides of an equation by that number.
  3. Add a multiple of one row to another row. This is how we remove a variable from an equation.

All three moves are reversible. That is why they keep the same solutions. We must carry out an operation across the whole row, including the constant after the bar.

Removing an entry

Start with

\[\left[\begin{array}{cc|c}1&3&5\\2&1&4\end{array}\right].\]

We want a zero in the lower-left corner. Subtract twice the first row from the second:

\[ R_2\leftarrow R_2-2R_1,\qquad \left[\begin{array}{cc|c}1&3&5\\0&-5&-6\end{array}\right]. \]

The arrow means that we replace row 2 with the result. The top row stays exactly as it was. The new second row tells us \(-5y=-6\), so \(y=6/5\). The first row then determines \(x\).

Multiplying a row by zero is not allowed. It would erase an equation, so the new system could have solutions that did not satisfy the original equations.
Try it. Starting with \(\left[\begin{array}{cc|c}1&2&5\\3&-1&4\end{array}\right]\), apply \(R_2\leftarrow R_2-3R_1\). What is the new second row?
Check the row

\([\,0\quad-7\mid-11\,]\). Subtract three times each entry of row 1 from the corresponding entry of row 2.

3. Making a staircase of zeros

Last week we learned that a triangular system is easy to solve: we find the bottom variable first and work upward. We want to create that same arrangement in a matrix.

Our goal is a staircase of leading entries. Below each leading entry, we make zeros. This arrangement is called row echelon form. A leading entry used to clear other entries is called a pivot.

The systematic process of making this staircase is called Gaussian elimination.

Example: solve a three-variable system

Start with the matrix

\[ \left[\begin{array}{ccc|c} 1&1&1&6\\ 2&-1&1&3\\ 1&2&-1&2 \end{array}\right]. \]

Its rows stand for the equations \(x+y+z=6\), \(2x-y+z=3\), and \(x+2y-z=2\).

First, clear the entries below the top-left 1. Replace row 2 by row 2 minus twice row 1, and row 3 by row 3 minus row 1.

\[ \left[\begin{array}{ccc|c} 1&1&1&6\\ 0&-3&-1&-9\\ 0&1&-2&-4 \end{array}\right]. \]

There are now two zeros under the first pivot.

Next, work on the second column. Swap rows 2 and 3, so the second row begins with a convenient 1.

\[ \left[\begin{array}{ccc|c} 1&1&1&6\\ 0&1&-2&-4\\ 0&-3&-1&-9 \end{array}\right]. \]

Now add three times row 2 to row 3 to remove its \(y\)-entry:

\[ \left[\begin{array}{ccc|c} 1&1&1&6\\ 0&1&-2&-4\\ 0&0&-7&-21 \end{array}\right]. \]

The matrix is in echelon form. Put the variables back in and read from the bottom:

\[ \begin{aligned} -7z&=-21 &&\Rightarrow z=3,\\ y-2z&=-4 &&\Rightarrow y=2,\\ x+y+z&=6 &&\Rightarrow x=1. \end{aligned} \]

The solution is \((1,2,3)\). Check it in the three original equations: \(1+2+3=6\), \(2-2+3=3\), and \(1+4-3=2\).

Notice that Gaussian elimination did not require a new algebraic trick. It organized the familiar work of eliminating variables. The important thing was to make the equations easier before solving for all the variables.

The Gaussian Elimination Workbench lets you try these steps yourself. Begin with a unique-solution preset, make zeros below the pivots, and then use the displayed matrix to solve.

Try it. The matrix \(\left[\begin{array}{ccc|c}1&2&-1&4\\0&1&3&5\\0&0&2&6\end{array}\right]\) is already in echelon form. Find \(z\), then \(y\), then \(x\).
Check your work

\(2z=6\) gives \(z=3\). Then \(y+9=5\), so \(y=-4\). Finally \(x+2(-4)-3=4\), so \(x=15\).

4. Reading the answer from the rows

Remember the three possibilities from Week 9: one solution, no solution, and infinitely many solutions. We can recognize them in the final matrix, even before calculating every variable.

A row that cannot be true

Consider this elimination:

\[ \left[\begin{array}{cc|c}1&-1&2\\2&-2&7\end{array}\right] \longrightarrow \left[\begin{array}{cc|c}1&-1&2\\0&0&3\end{array}\right]. \]

The bottom row says \(0x+0y=3\), or \(0=3\). That is impossible. No numbers satisfy both original equations, so there is no solution.

A row that adds no new information

Now suppose we begin with

\[ \left[\begin{array}{cc|c}1&2&3\\2&4&6\end{array}\right]. \]

Subtract twice the first row from the second. We get an all-zero row, which says \(0=0\). It is always true and does not determine another variable. The remaining equation is \(x+2y=3\), so we can choose \(y=t\) and then \(x=3-2t\). There are infinitely many solutions, written \((3-2t,t)\).

Here's the pattern to remember:

Three outcomes in echelon form

  1. One solution: no contradiction, and every variable column has a leading entry.
  2. No solution: a row has zeros in all variable columns but a nonzero constant, such as \([\,0\ 0\mid3\,]\).
  3. Infinitely many solutions: there is no contradiction and at least one variable column has no leading entry. That variable can be chosen freely.

An all-zero row by itself does not guarantee infinitely many solutions in every rectangular system. What matters is whether any variables remain free once all the nonzero equations have been considered.

Try it. A system ends with the row \([\,0\quad0\quad0\mid5\,]\). What does this say about its solutions? What if the last entry were also zero?
Check your reasoning

The first row says \(0=5\), so there is no solution. If every entry is zero, the row contributes no new condition; you then need to inspect the remaining rows to see whether any variables are free.

5. Application: electric currents

What does a system of equations have to do with electricity? In a circuit, electric charge flows along wires. At a junction, the amount of charge entering each second must equal the amount leaving. That gives us an equation.

There are also conditions about voltage around loops of a circuit. The voltage supplied by a battery is accounted for by drops across components; for a resistor, the drop is resistance times current, \(V=IR\). Together these statements give simultaneous linear equations.

A two-loop circuit

Suppose a circuit has three branch currents \(I_1,I_2,I_3\), measured in amperes. A junction and two loop calculations give us these three conditions:

\[\begin{aligned} I_1-I_2-I_3&=0 &&\text{(currents at the junction)},\\ 2I_1+3I_2&=12 &&\text{(left loop)},\\ 3I_2+4I_3&=10 &&\text{(right loop)}. \end{aligned}\]

We will use these equations as the description of the circuit; no previous electronics course is needed. Their augmented matrix is

\[ \left[\begin{array}{ccc|c} 1&-1&-1&0\\ 2&3&0&12\\ 0&3&4&10 \end{array}\right]. \]

Replace row 2 by \(R_2-2R_1\). This removes \(I_1\) from the second row:

\[ \left[\begin{array}{ccc|c} 1&-1&-1&0\\ 0&5&2&12\\ 0&3&4&10 \end{array}\right]. \]

Next, take five times row 3 minus three times row 2. The result is a row that says \(14I_3=14\). Hence \(I_3=1\). Then \(5I_2+2=12\) gives \(I_2=2\), and the first row gives \(I_1=3\).

As a check, the current entering the junction is \(3\) amperes and the total leaving is \(2+1=3\). The numbers satisfy the physical requirement.

Notice the connection: a law about physical conservation became an equation, and the equations became a matrix. The matrix helped us find numbers consistent with all the conditions.

6. Application: balancing a chemical reaction

When a chemical reaction occurs, the atoms are rearranged, but the number of atoms of each element is conserved. We can use a system of equations to find the coefficients needed to balance a reaction.

Burning propane

Propane has chemical formula \(\mathrm{C_3H_8}\). It reacts with oxygen to produce carbon dioxide and water. We want to balance

\[ a\,\mathrm{C_3H_8}+b\,\mathrm{O_2} \longrightarrow c\,\mathrm{CO_2}+d\,\mathrm{H_2O}. \]

The unknowns \(a,b,c,d\) tell us how many units of each substance take part. Count the atoms of carbon, hydrogen, and oxygen on each side:

\[ \begin{aligned} 3a&=c &&\text{(carbon)},\\ 8a&=2d &&\text{(hydrogen)},\\ 2b&=2c+d &&\text{(oxygen)}. \end{aligned} \]

There are four unknown coefficients but only three conditions. This makes sense: if a reaction is balanced, doubling all its coefficients keeps it balanced. So we choose one of the coefficients and express the others in terms of it.

Let \(a=t\). The first equation gives \(c=3t\), and the second gives \(d=4t\). The oxygen equation then becomes \(2b=2(3t)+4t=10t\), so \(b=5t\).

Choosing \(t=1\) gives the smallest positive whole-number coefficients:

\[ \mathrm{C_3H_8}+5\,\mathrm{O_2} \longrightarrow3\,\mathrm{CO_2}+4\,\mathrm{H_2O}. \]

This is an example of a system with a free parameter. The parameter tells us how many times to scale the entire reaction.

Try it. To balance \(a\,\mathrm{Fe}+b\,\mathrm{O_2}\to c\,\mathrm{Fe_2O_3}\), start by writing the equations for iron atoms and oxygen atoms. Can you find the smallest positive integer values for \(a,b,c\)?
Check your balance

The equations are \(a=2c\) and \(2b=3c\). Choosing \(c=2\) gives \(a=4\) and \(b=3\), so \(4\,\mathrm{Fe}+3\,\mathrm{O_2}\to2\,\mathrm{Fe_2O_3}\).

7. Application: traffic through a network

The same conservation idea appears in road systems. Suppose we count the cars entering and leaving several intersections during an hour. If traffic is not building up at an intersection, then the number entering must equal the number leaving.

Four connected road segments

Suppose a small network has four unknown one-way flows \(x_1,x_2,x_3,x_4\), in cars per hour. The counts entering and leaving its intersections give

\[ \begin{aligned} x_1+x_2&=800,\\ x_2&=x_3+200,\\ x_3+x_4&=600,\\ x_1&=x_4. \end{aligned} \]

The last equation tells us immediately that \(x_1=x_4\). Let \(x_4=t\), and use the other equations to find the remaining flows:

\[ x_1=t,\quad x_2=800-t,\quad x_3=600-t,\quad x_4=t. \]

What about the second equation? Substitution gives \(800-t=(600-t)+200\), which is always true. We have not missed an equation; it simply repeats information already contained in the others.

The system does not determine one single pattern of traffic. Different values of \(t\) are possible. But cars per hour cannot be negative. Since \(x_4=t\) and \(x_3=600-t\), we need

\[ 0\leq t\leq600. \]

The equations give us a family of possible traffic patterns. An extra measurement of one segment would determine which pattern is actually occurring.

Here, a free variable tells us something practical: we do not yet have enough information to know every traffic flow. Sometimes discovering what we cannot determine is as useful as finding a single answer.

8. Returning to functions: fitting a quadratic

One more connection brings us back to the beginning of our course. Earlier we worked with quadratic functions of the form \(y=ax^2+bx+c\). Usually we were given the coefficients and asked to study the graph. Now we can reverse the question: if we know three points on a parabola, can we find its equation?

A parabola through three points

Suppose the graph passes through \((0,2)\), \((1,5)\), and \((3,23)\). Put each point into \(y=ax^2+bx+c\):

\[ \begin{aligned} c&=2,\\ a+b+c&=5,\\ 9a+3b+c&=23. \end{aligned} \]

These are linear equations in the unknown coefficients \(a,b,c\). We can arrange them as a matrix:

\[ \left[\begin{array}{ccc|c} 0&0&1&2\\ 1&1&1&5\\ 9&3&1&23 \end{array}\right]. \]

The first row gives \(c=2\). Using that in the other two equations leaves \(a+b=3\) and \(3a+b=7\). Subtract the first from the second: \(2a=4\), so \(a=2\). Then \(b=1\).

Our quadratic is \(y=2x^2+x+2\). Check: at \(x=0\), the output is 2; at \(x=1\), it is 5; and at \(x=3\), it is 23.

Try the Quadratic Fit by Matrix activity to repeat this process with other points. When three points have distinct \(x\)-values, exactly one quadratic polynomial of degree at most two passes through them (it may turn out to have \(a=0\), giving a line). That result is a beautiful meeting point between systems of equations and functions.

We began this course asking how functions describe data and relationships. Matrices give us one more tool for moving in the other direction: using data to determine the function.

Write down intermediate rows when you perform elimination. When an answer comes from a model, check it in the original equations and explain what the numbers represent.

  1. Write the augmented matrix of \(\begin{aligned}3x-y+2z&=5\\x+4y-z&=0\\2x+y+z&=7\end{aligned}\), labeling which column belongs to which variable.
  2. State the three elementary row operations and the equation operation each represents.
  3. Apply one row operation to clear the first column below the top entry of \(\left[\begin{array}{cc|c}1&3&5\\2&1&4\end{array}\right]\), and write the result.
  4. Solve by Gaussian elimination: \(\left[\begin{array}{cc|c}1&2&5\\3&1&5\end{array}\right]\), and state the solution as a point.
  5. Carry \(\left[\begin{array}{ccc|c}1&1&1&4\\2&1&-1&3\\1&-2&3&11\end{array}\right]\) to echelon form and solve by back-substitution; check your answer.
  6. Eliminate \(\left[\begin{array}{cc|c}1&-2&3\\-3&6&5\end{array}\right]\) and state the outcome, identifying the row that reveals it.
  7. Eliminate \(\left[\begin{array}{cc|c}2&4&6\\3&6&9\end{array}\right]\), identify the free variable, and write the solution set with a parameter.
  8. Explain how each of the three outcomes, unique, none, and infinitely many, appears in echelon form.
  9. A system's echelon form has a bottom row \([\,0\ 0\ 0\mid5\,]\). State the outcome and explain the reasoning in one sentence.
  10. Balance \(a\,\mathrm{Fe}+b\,\mathrm{O_2}\to c\,\mathrm{Fe_2O_3}\) by writing the atom-count equations as a linear system and choosing the smallest whole-number solution.
  11. A two-loop circuit gives the system \(\begin{aligned}I_1-I_2-I_3&=0\\I_1+2I_2&=10\\2I_2+3I_3&=9\end{aligned}\) for its branch currents. Solve by Gaussian elimination, and verify the junction law \(I_1=I_2+I_3\).
  12. Explain why Gaussian elimination on a matrix and elimination on the original equations produce the same solution, and why the matrix form is useful for larger systems.
