Part I: Radicals and Rational Exponents

1. Simplify completely. Assume variables are nonnegative unless otherwise stated.

(a) Simplify \(\sqrt{72}\) completely.
Worked solution
\(\sqrt{72}=\sqrt{36\cdot2}=6\sqrt2.\)
(b) Simplify \(\sqrt{50x^3}\) completely.
Worked solution
\(\sqrt{50x^3}=\sqrt{25x^2(2x)}=5x\sqrt{2x}.\)
(c) Simplify \(\sqrt[3]{54a^4}\) completely.
Worked solution
\(\sqrt[3]{54a^4}=\sqrt[3]{27a^3(2a)}=3a\sqrt[3]{2a}.\)
(d) Evaluate \(16^{3/4}\).
Worked solution
\(16^{3/4}=(16^{1/4})^3=2^3=8.\)
(e) Evaluate \(27^{-2/3}\).
Worked solution
\(27^{-2/3}=\dfrac{1}{(27^{1/3})^2}=\dfrac19.\)
(f) Rewrite \(x^{5/2}\) in radical form.
Worked solution
\(x^{5/2}=x^2x^{1/2}=x^2\sqrt{x}.\)

2. Rewrite each expression in the other form.

(a) Rewrite \(\sqrt[3]{x^5}\) using a rational exponent.
Worked solution
\(\sqrt[3]{x^5}=x^{5/3}.\)
(b) Rewrite \(y^{7/4}\) in radical form.
Worked solution
\(y^{7/4}=\sqrt[4]{y^7}\) (equivalently \(y\sqrt[4]{y^3}\)).
(c) Rewrite \(\dfrac1{\sqrt{x}}\) using a rational exponent.
Worked solution
\(\dfrac1{\sqrt{x}}=x^{-1/2}.\)
(d) Rewrite \(z^{-5/3}\) in radical form without a negative exponent.
Worked solution
\(z^{-5/3}=\dfrac1{\sqrt[3]{z^5}}.\)

3. Solve. Check for extraneous solutions.

(a) Solve \(\sqrt{2x+3}=x\). Check any proposed solutions in the original equation.
Worked solution
Square: \(2x+3=x^2\), so \((x-3)(x+1)=0\). Testing the original rejects \(-1\). Thus \(x=3\).
(b) Solve \(\sqrt{x+7}-2=3\). Check any proposed solutions in the original equation.
Worked solution
\(\sqrt{x+7}=5\Rightarrow x+7=25\Rightarrow x=18.\)

4. State the domain in interval notation.

(a) State the domain of \(f(x)=\sqrt{5-2x}\) in interval notation.
Worked solution
Require \(5-2x\ge0\), so \(x\le5/2\). Domain: \((-\infty,5/2]\).
(b) State the domain of \(g(x)=\dfrac{\sqrt{x-4}}{x+1}\) in interval notation.
Worked solution
The square root requires \(x\ge4\). The denominator restriction \(x\ne-1\) is already outside that set. Domain: \([4,\infty)\).
Part II: Exponential Functions

5. Evaluate without a calculator.

(a) Evaluate \(2^{-4}\) without a calculator.
Worked solution
\(2^{-4}=1/2^4=1/16.\)
(b) Evaluate \(25^{1/2}\) without a calculator.
Worked solution
\(25^{1/2}=\sqrt{25}=5.\)
(c) Evaluate \(8^{2/3}\) without a calculator.
Worked solution
\(8^{2/3}=(\sqrt[3]{8})^2=2^2=4.\)
(d) Evaluate \(10^0\) without a calculator.
Worked solution
Any nonzero base to the zero power is \(1\).
(e) Evaluate \((1/3)^{-2}\) without a calculator.
Worked solution
\((1/3)^{-2}=3^2=9.\)
(f) Evaluate \(e^0\) without a calculator.
Worked solution
\(e^0=1.\)

6. Consider \(f(x)=3\cdot 2^{x-1}-4\).

(a) Is \(f(x)=3\cdot2^{x-1}-4\) an exponential growth function or an exponential decay function?
Worked solution
The base is \(2>1\), so this is exponential growth.
(b) What is the horizontal asymptote of \(f(x)=3\cdot2^{x-1}-4\)?
Worked solution
The graph is shifted down \(4\), so the horizontal asymptote is \(y=-4\).
(c) Find the \(y\)-intercept of \(f(x)=3\cdot2^{x-1}-4\).
Worked solution
\(f(0)=3\cdot2^{-1}-4=3/2-4=-5/2.\) The intercept is \((0,-5/2)\).
(d) Describe the transformations that take \(y=2^x\) to \(f(x)=3\cdot2^{x-1}-4\).
Worked solution
Shift right \(1\), stretch vertically by a factor of \(3\), then shift down \(4\).

7. Solve exactly when possible.

(a) Solve the exponential equation \(5^{2x-1}=125\).
Worked solution
\(125=5^3\), so \(2x-1=3\), hence \(x=2\).
(b) Solve the exponential equation \(4^{x+2}=17\). Give an exact logarithmic answer or a decimal approximation.
Worked solution
\((x+2)\ln4=\ln17\), so \[x=\frac{\ln17}{\ln4}-2\approx0.044.\]

8. Population model: \(\displaystyle P(t)=250(1.06)^t\), with \(t\) in years.

(a) For \(P(t)=250(1.06)^t\), what is the initial population?
Worked solution
\(P(0)=250(1.06)^0=250.\)
(b) For \(P(t)=250(1.06)^t\), what percent does the population grow each year?
Worked solution
The growth factor is \(1.06=1+0.06\), so the annual growth rate is \(6\%\).
(c) For \(P(t)=250(1.06)^t\), find the population after 8 years.
Worked solution
\(P(8)=250(1.06)^8\approx398.462.\)
(d) For \(P(t)=250(1.06)^t\), after how many years will the population reach 400?
Worked solution
\[250(1.06)^t=400\Rightarrow t=\frac{\ln(400/250)}{\ln(1.06)}\approx8.066\text{ years}.\] At whole-year observations, the population first exceeds \(400\) during year \(9\).

9. Radioactive sample: \(\displaystyle A(t)=120\left(\frac12\right)^{t/5}\).

(a) For \(A(t)=120\left(\frac12\right)^{t/5}\), what is the half-life of the sample?
Worked solution
The exponent is \(t/5\), so one factor of \(1/2\) occurs every \(5\) years.
(b) For \(A(t)=120\left(\frac12\right)^{t/5}\), how many milligrams remain after 12 years?
Worked solution
\(A(12)=120(1/2)^{12/5}\approx22.736\) mg.
(c) For \(A(t)=120\left(\frac12\right)^{t/5}\), after how many years will 30 mg remain?
Worked solution
\(30/120=1/4=(1/2)^2\), so \(t/5=2\), hence \(t=10\) years.
Part III: Logarithms

10. Rewrite each equation in the other form.

(a) Rewrite \(2^5=32\) in logarithmic form.
Worked solution
\(\log_2 32=5.\)
(b) Rewrite \(10^{-3}=0.001\) in logarithmic form.
Worked solution
\(\log(0.001)=-3.\)
(c) Rewrite \(\log_3 81=4\) in exponential form.
Worked solution
\(3^4=81.\)
(d) Rewrite \(\ln 7=x\) in exponential form.
Worked solution
\(e^x=7.\)

11. Evaluate exactly.

(a) Evaluate \(\log_2 32\) exactly.
Worked solution
Because \(2^5=32\), \(\log_2 32=5\).
(b) Evaluate \(\log(0.001)\) exactly.
Worked solution
\(0.001=10^{-3}\), so \(\log(0.001)=-3\).
(c) Evaluate \(\ln(e^4)\) exactly.
Worked solution
\(\ln\) and \(e^x\) are inverses, so \(\ln(e^4)=4\).
(d) Evaluate \(e^{\ln7}\) exactly.
Worked solution
\(e^x\) and \(\ln x\) are inverses, so \(e^{\ln7}=7\).
(e) Evaluate \(\log_5 1\) exactly.
Worked solution
Since \(5^0=1\), \(\log_5 1=0\).
(f) Evaluate \(\log_3(1/27)\) exactly.
Worked solution
\(1/27=3^{-3}\), so the logarithm is \(-3\).

12. Use logarithm laws.

(a) Expand \(\log\!\left(\dfrac{x^3\sqrt y}{z^2}\right)\) using logarithm laws.
Worked solution
\[3\log x+\frac12\log y-2\log z.\]
(b) Condense \(2\ln x-\frac12\ln(x+1)+\ln3\) into a single logarithm.
Worked solution
\[\ln\!\left(\frac{3x^2}{\sqrt{x+1}}\right).\]

13. Solve. State any domain restriction you use.

(a) Solve \(\log_2(x-3)=4\). State the domain restriction you use.
Worked solution
Domain: \(x>3\). Then \(x-3=2^4=16\), so \(x=19\).
(b) Solve \(\ln(2x+1)=3\). State the domain restriction you use.
Worked solution
Domain: \(x>-1/2\). Then \(2x+1=e^3\), so \[x=\frac{e^3-1}{2}\approx9.543.\]
(c) Solve \(\log x+\log(x-9)=1\). State the domain restriction you use and check your solution.
Worked solution
Domain: \(x>9\). Combine logs: \(\log[x(x-9)]=1\), so \(x(x-9)=10\). The algebraic candidates are \(10,-1\), and only \(x=10\) satisfies the domain.

14. Use change of base to approximate \(\log_7 20\) to three decimals.

Use change of base to approximate \(\log_7 20\) to three decimal places.
Worked solution
\[\log_7 20=\frac{\ln20}{\ln7}\approx1.540.\]
Part IV: Systems of Two Equations in Two Unknowns

15. Solve each system. Use substitution or elimination.

(a) Solve the system \(\begin{cases}x+y=7\\2x-y=5\end{cases}\). Give your answer as an ordered pair.
Worked solution
Add the equations: \(3x=12\), so \(x=4\). Then \(y=3\). Solution: \((4,3)\).
(b) Solve the system \(\begin{cases}3x+2y=16\\5x-2y=8\end{cases}\). Give your answer as an ordered pair.
Worked solution
Add the equations: \(8x=24\), so \(x=3\). Then \(9+2y=16\), so \(y=7/2\). Solution: \((3,7/2)\).
(c) Solve the system \(\begin{cases}2x+4y=6\\x+2y=5\end{cases}\), or state that it has no solution or infinitely many solutions.
Worked solution
The first equation simplifies to \(x+2y=3\), while the second says \(x+2y=5\). Contradiction: no solution.
(d) Solve the system \(\begin{cases}3x-y=7\\6x-2y=14\end{cases}\), or state that it has no solution or infinitely many solutions.
Worked solution
The second equation is exactly twice the first, so both equations describe the same line. There are infinitely many solutions.

16. Find the intersection algebraically.

\[y=2x+1,\qquad y=-x+7.\]
Find the point of intersection of \(y=2x+1\) and \(y=-x+7\). Give your answer as an ordered pair.
Worked solution
Set the two formulas equal: \(2x+1=-x+7\Rightarrow3x=6\Rightarrow x=2\). Then \(y=5\), so the intersection is \((2,5)\).

17. Ticket problem.

A school play sells \(120\) tickets. Adult tickets cost \(\$12\) and student tickets cost \(\$7\). Total revenue is \(\$1090\).

(a) Define variables for the number of adult tickets and the number of student tickets.
Worked solution
One choice is \(A=\) number of adult tickets and \(S=\) number of student tickets.
(b) Write a system of two equations that models the ticket problem.
Worked solution
\[\begin{cases}A+S=120\\12A+7S=1090\end{cases}\]
(c) Solve the system and state how many adult tickets and how many student tickets were sold.
Worked solution
Substitute \(S=120-A\): \(12A+7(120-A)=1090\Rightarrow5A=250\Rightarrow A=50\). Then \(S=70\). There were \(50\) adult tickets and \(70\) student tickets.
Part V: Mixed Review — Choose the Method

18. Solve each problem. Decide which tool belongs to the problem.

(a) Solve \(\sqrt{3x+10}=x+2\). Check for extraneous solutions.
Worked solution
Square both sides: \(3x+10=x^2+4x+4\), so \((x-2)(x+3)=0\). Checking the original rejects \(x=-3\), leaving \(x=2\).
(b) Solve \(3^{2x}=20\). Give an exact logarithmic answer or a decimal approximation.
Worked solution
Take logs: \(2x\ln3=\ln20\), so \[x=\frac{\ln20}{2\ln3}\approx1.363.\]
(c) Solve \(\ln(x-1)+\ln(x+1)=\ln8\). State the domain restriction and check your answer.
Worked solution
Domain requires \(x>1\). Then \(\ln[(x-1)(x+1)]=\ln8\), so \(x^2-1=8\), giving \(x=\pm3\). The domain leaves \(x=3\).
(d) Solve the system \(\begin{cases}4x+3y=1\\2x-y=7\end{cases}\). Give your answer as an ordered pair.
Worked solution
From \(2x-y=7\), \(y=2x-7\). Substitute: \(4x+3(2x-7)=1\Rightarrow10x=22\), so \(x=11/5\), \(y=-13/5\).

19. For each cue, name the method it suggests.

If the unknown appears inside a square root, what method should you use to solve the equation?
Answer
Isolate the radical, square both sides, solve, and check for extraneous solutions.
If the unknown appears in an exponent, what method should you use to solve the equation?
Answer
Use a common base if possible; otherwise take logarithms.
If two logarithms are being added, which logarithm law can you use to combine them?
Answer
Use the product law to combine the logarithms, while keeping domain restrictions in mind.
If you have two linear equations in the same two unknowns, which algebraic methods can you use to solve the system?
Answer
Use substitution or elimination.
