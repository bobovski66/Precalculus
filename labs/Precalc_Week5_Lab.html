Problem 1 — Domain from the operations

A domain is restricted only by division (no zero denominator) and even roots (no negative radicand). For each function, enter the boundary value asked for.
(a) \(f(x)=\dfrac{1}{x-5}\): the domain is all reals except one value. Enter the excluded \(x\).
Show solution

Exclude \(x=5\).

The denominator \(x-5\) vanishes at \(x=5\), where the function is undefined.

(b) \(g(x)=\sqrt{x-3}\): the domain is \(x\ge c\). Enter \(c\).
Show solution

\(c=3\), so the domain is \(x\ge3\).

An even root requires a nonnegative radicand: \(x-3\ge0\).

(c) Explain why \(\sqrt[3]{x}\) accepts negative inputs but \(\sqrt{x}\) does not.
Show solution

Odd roots of negatives are real; even roots of negatives are not.

A cube root inverts \(x^{3}\), which takes all real values including negatives, so \(\sqrt[3]{-8}=-2\) is real. A square root inverts \(x^{2}\), which is never negative, so there is no real square root of a negative number.

(a) \(f(x)=2x-1\)

Yes.

A non-horizontal line meets every horizontal line exactly once.

(b) \(f(x)=x^{2}\)
Show solution

No.

The line \(y=4\) meets the parabola at \(x=2\) and \(x=-2\), two inputs sharing one output. Restricting to \(x\ge0\) would make it one-to-one.

Problem 3 — Finding an inverse

Let \(f(x)=3x-7\).
(a) The inverse has the form \(f^{-1}(x)=\dfrac{x+a}{b}\). Enter \(a\) and \(b\).
Show solution

\(f^{-1}(x)=\dfrac{x+7}{3}\), so \(a=7,\ b=3\).

Write \(y=3x-7\), swap to \(x=3y-7\), and solve: \(y=\dfrac{x+7}{3}\).

(b) Verify by computing \(f^{-1}(f(2))\). Enter the result.
Show solution

\(f^{-1}(f(2))=2\).

\(f(2)=3(2)-7=-1\), then \(f^{-1}(-1)=\dfrac{-1+7}{3}=2\). An inverse returns the original input.

(c) Explain why the graph of \(f^{-1}\) is the reflection of \(f\) across the line \(y=x\).
Show solution

Swapping input and output sends each point \((a,b)\) to \((b,a)\), which is its mirror image across \(y=x\).

The inverse is defined by exchanging the roles of \(x\) and \(y\). Reflecting every point of the graph across the diagonal \(y=x\) produces exactly that swap, so the two graphs are mirror images.

Problem 4 — A radical equation

Solve \(\sqrt{x+5}=x-1\), checking each candidate.
(a) Squaring gives a quadratic. Enter its two candidate solutions (smaller first).
Show solution

Candidates \(x=-1\) and \(x=4\).

Squaring: \(x+5=x^{2}-2x+1\), so \(x^{2}-3x-4=0\), giving \((x-4)(x+1)=0\).

(b) Check each in the original equation. Enter the one valid solution.
Show solution

Only \(x=4\) is valid.

\(x=4\): \(\sqrt{9}=3\) and \(4-1=3\). ✓. \(x=-1\): \(\sqrt{4}=2\) but \(-1-1=-2\); the two sides disagree, so \(-1\) is rejected.

(c) Explain why squaring both sides can introduce a false solution.
Show solution

Squaring forgets sign: \(\sqrt{\,}\) returns the nonnegative root, but squaring accepts both signs.

The equation \(\sqrt{x+5}=x-1\) requires the right side to be nonnegative. Squaring drops that requirement, so a candidate making the right side negative can satisfy the squared equation while failing the original. Checking each candidate catches it.
