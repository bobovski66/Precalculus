Problem 1 — Linear or exponential?

Each table gives outputs at \(x=0,1,2,3\). Decide the model type and the parameter asked for.
(a) Outputs \(3,6,12,24\). Enter \(1\) if exponential or \(0\) if linear, then the common ratio or difference.
Show solution

Exponential, common ratio \(2\): \(f(x)=3\cdot2^{x}\).

Each output is twice the last, a constant ratio, which is the signature of exponential growth.

(b) Outputs \(5,8,11,14\). Enter \(1\) if exponential or \(0\) if linear, then the common ratio or difference.
Show solution

Linear, common difference \(3\): \(f(x)=3x+5\).

Each output is \(3\) more than the last, a constant difference, the signature of linear growth.

(c) Explain how you can tell exponential from linear by looking at successive outputs.
Show solution

Linear has equal differences; exponential has equal ratios.

Subtract successive outputs: a constant difference means linear. Divide successive outputs: a constant ratio means exponential. One adds a fixed amount per step, the other multiplies by a fixed factor.

Problem 2 — The number \(e\) and continuous growth

A bank account of \$1000 grows continuously at \(4\%\) per year, modeled by \(A(t)=1000\,e^{0.04t}\).
Fit an exponential to a point cloud in the Function Fit Lab: set the parent to an exponential and tune the parameters.
(a) Find the balance after \(10\) years (round to the nearest cent / two decimals).
Show solution

\(A(10)=1000\,e^{0.4}\approx \$1491.82.\)

\(e^{0.4}\approx1.49182\), so the balance is about \$1491.82.

(b) The compounding factor \(\left(1+\tfrac1n\right)^{n}\) rises toward a fixed ceiling as \(n\) grows. Enter that ceiling to two decimals.
Show solution

The ceiling is \(e\approx2.72\).

As compounding is refined, the factor climbs and settles toward \(e=2.71828\ldots\), the base of continuous growth.

(c) Explain why \(\left(1+\tfrac1n\right)^{n}\) does not grow without bound as \(n\) increases.
Show solution

Each finer compounding adds less than the one before, and the total stays trapped beneath a fixed height.

Splitting the year into more periods does add a little extra growth, but each added piece is smaller than the last. The running total presses upward against a ceiling it never crosses; that ceiling is \(e\).

Problem 3 — Half-life

A radioactive sample has a half-life of \(10\) years, starting from \(64\) grams, modeled by \(M(t)=64\left(\tfrac12\right)^{t/10}\).
(a) Find the mass remaining after \(10\), \(20\), and \(30\) years (no logarithms needed).
Show solution

\(32,\ 16,\ 8\) grams.

Each \(10\) years is one half-life, halving the mass: \(64\to32\to16\to8\).

(b) A sample is measured at one-eighth of its original content. How many half-lives have passed?
Show solution

Three half-lives.

\(\left(\tfrac12\right)^{3}=\tfrac18\), so three halvings bring the sample to one-eighth.

(c) Explain why a radioactive sample's mass is exponential rather than decreasing by a fixed amount each year.
Show solution

It loses a fixed fraction, not a fixed amount, in each equal time span.

Each half-life removes half of whatever is present, so the amount removed shrinks as the sample shrinks. Constant-ratio decrease is exponential; subtracting a fixed amount would be linear and would reach zero in finite time, which radioactive decay never does.
