Objectives

  • Write the augmented matrix of a linear system.

Problem 1 — Gaussian elimination

Solve the system whose augmented matrix is \[ \left[\begin{array}{ccc|c} 1&1&1&4\\ 2&-1&1&8\\ 1&2&-1&-3 \end{array}\right]. \]
(a) Reduce to echelon form and back-substitute. Enter \(x\), \(y\), \(z\).
Show solution

\((x,y,z)=(2,-1,3)\).

Use \(R_2\leftarrow R_2-2R_1\) and \(R_3\leftarrow R_3-R_1\). Then combine the last two rows to obtain \(-7z=-21\), so \(z=3\); back-substitution gives \(y=-1\) and \(x=2\).

(b) Name the three elementary row operations and the equation operation each represents.
Show solution

Swap two rows; scale a row by a nonzero constant; replace a row by itself plus a multiple of another. These correspond to reordering equations, multiplying an equation by a nonzero number, and adding a multiple of one equation to another.

Problem 2 — Reading the outcome

Use the echelon form itself to classify each system.
(a) For \(\left[\begin{array}{cc|c}1&3&4\\0&2&-6\end{array}\right]\), enter \(1\) for unique, \(0\) for none, or \(2\) for infinitely many.
Show solution

Unique solution.

There is a pivot in each variable column and no contradictory row.

(b) For \(\left[\begin{array}{cc|c}1&-2&5\\0&0&-4\end{array}\right]\), enter the outcome code.
Show solution

No solution.

The bottom row means \(0=-4\), a contradiction.

(c) For \(\left[\begin{array}{ccc|c}1&1&-2&3\\0&1&4&2\\0&0&0&0\end{array}\right]\), enter the outcome code and explain why.
Show solution

Infinitely many solutions.

There are three variables but only two pivot rows, so one variable is free. The zero row adds no new constraint.

Problem 3 — Currents in a circuit

Kirchhoff's laws give the branch currents of a two-loop circuit: \(\begin{aligned}I_1-I_2-I_3&=0\\ I_1+2I_2&=10\\ 2I_2+3I_3&=9\end{aligned}\)
(a) Solve by Gaussian elimination. Enter \(I_1\), \(I_2\), \(I_3\) in amperes.
Show solution

\(I_1=4,\ I_2=3,\ I_3=1\) amperes.

From row 2, \(I_1=10-2I_2\). Substituting into the junction equation and using row 3 leads to \(I_2=3\), \(I_3=1\), \(I_1=4\). The junction law checks: \(4=3+1\).

(b) Verify the junction law \(I_1=I_2+I_3\) with your values, and explain what it expresses physically.
Show solution

\(4=3+1\). The current flowing into a junction equals the current flowing out.

Charge is conserved: it cannot pile up at a junction, so the current entering must equal the total leaving. This is Kirchhoff's current law.

Problem 4 — Fitting a quadratic with a matrix

A quadratic \(y=ax^2+bx+c\) passes through \((0,2)\), \((1,5)\), and \((3,23)\).
(a) Write the three linear equations for \(a,b,c\) and the corresponding augmented matrix.
Show solution

\(c=2,\quad a+b+c=5,\quad 9a+3b+c=23\).

The augmented matrix is \(\left[\begin{array}{ccc|c}0&0&1&2\\1&1&1&5\\9&3&1&23\end{array}\right]\).

(b) Use Gaussian elimination to solve for \(a,b,c\), then write the quadratic.
Show solution

\(a=2,\ b=1,\ c=2\), so \(y=2x^2+x+2\).

Substituting \(c=2\) leaves \(a+b=3\) and \(3a+b=7\), which gives \(a=2\) and \(b=1\).
