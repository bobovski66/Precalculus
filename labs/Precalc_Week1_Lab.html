Problem 1 — Relations, domain, range, and the function test

Consider the relation \(R=\{(-2,4),\,(0,1),\,(1,4),\,(1,-3),\,(3,2)\}\).
(a) How many distinct elements are in the domain of \(R\)? How many are in the range?
Show solution

Domain \(\{-2,0,1,3\}\): 4 elements. Range \(\{4,1,-3,2\}\): 4 elements.

The domain is the set of first coordinates. The input \(1\) appears twice but is counted once, so the domain has four elements. The range is the set of second coordinates; \(4\) appears twice but is listed once, leaving four values.

(b) Is \(R\) a function? Enter 1 for yes or 0 for no.
Show solution

No, \(R\) is not a function.

The input \(1\) is paired with two different outputs, \(4\) and \(-3\). A function requires each input to determine exactly one output, so a single input with two outputs disqualifies it.

(c) Change exactly one ordered pair so that \(R\) becomes a function, and explain why your change works.
Show solution

Replace \((1,-3)\) with any pair whose input is not already used, for example \((2,-3)\).

The only obstruction was that \(1\) had two outputs. Moving one of those pairs to a fresh input removes the conflict, and every input now has a single output. Replacing \((1,4)\) instead would work equally well; what matters is eliminating the repeated input.

Problem 2 — Evaluating a function

Let \(f(x)=2x^{2}-3x+1\).
(a) Compute \(f(0)\), \(f(2)\), and \(f(-1)\).
Show solution

\(f(0)=1,\quad f(2)=3,\quad f(-1)=6.\)

\(f(0)=2(0)-0+1=1\). \(f(2)=2(4)-3(2)+1=8-6+1=3\). \(f(-1)=2(1)-3(-1)+1=2+3+1=6\). Substitute the input everywhere \(x\) appears, then simplify.

(b) Expand \(f(t+1)\) completely. Enter the coefficients of the simplified form \(at^{2}+bt+c\).
Show solution

\(f(t+1)=2t^{2}+t\), so \(a=2,\ b=1,\ c=0\).

\(f(t+1)=2(t+1)^{2}-3(t+1)+1=2(t^{2}+2t+1)-3t-3+1 =2t^{2}+4t+2-3t-2=2t^{2}+t\). Evaluating at an expression means substituting the whole expression for \(x\), then expanding.

Problem 3 — Transformations

Start from the parent function \(f(x)=x^{2}\) and consider \(g(x)=-2\,(x-3)^{2}+5\).
(a) Read off the four transformation constants in \(A\,f(b(x-h))+k\). (Here \(b=1\).)
Show solution

\(A=-2,\ h=3,\ k=5.\)

The \(-2\) outside stretches vertically by \(2\) and reflects across the \(x\)-axis. The \((x-3)\) shifts right \(3\). The \(+5\) shifts up \(5\).

(b) The vertex of the parent \(x^{2}\) is at the origin. Give the vertex of \(g\).
Show solution

Vertex \((3,5)\).

The origin maps to \((h,k)=(3,5)\): the inside is zero at \(x=3\), and the \(+5\) lifts the output to \(5\). The reflection and stretch change the opening but not the vertex location.

(c) Does \(g\) open upward or downward? Enter 1 for upward or -1 for downward.
Show solution

Downward.

Because \(A=-2<0\), the parabola is reflected across the \(x\)-axis and opens downward. The vertex \((3,5)\) is therefore the highest point of the graph.

Problem 4 — Fitting a model to a point cloud

A cloud of data points rises steeply near \(x=0\), then bends and climbs gently as \(x\) grows, staying in the first quadrant.
Use the Function Fit Lab for this problem: generate a cloud, identify the parent family, and tune \(A\,f(b(x-h))+k\) until your curve threads the data.
(a) Which parent function best matches the described shape: linear, quadratic, square-root, or exponential? Open the solution after deciding.
Show solution

Square root, \(f(x)=\sqrt{x}\).

The "steep near zero, then gently rising" profile beginning in the first quadrant is the signature of \(\sqrt{x}\). A line would not bend; a parabola would curve the wrong way (slow then steep); an exponential would accelerate rather than flatten.
